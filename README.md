# thewisework

Código de la web de Wise Work, publicada en https://thewisework.com

## Contenido

- `index.html`: el sitio completo tal como está publicado en thewisework.com (2026-09-25). Es un único archivo autocontenido: estilos, scripts y recursos van embebidos, así que no necesita build ni dependencias.
- `LICENSE`: MIT No Attribution (MIT-0).

## Ver o crear un derivado

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en un navegador. No hace falta servidor.
3. Para publicarlo, subir `index.html` a cualquier hosting estático (Netlify, GitHub Pages, un hosting compartido, etc.) como página de inicio.
